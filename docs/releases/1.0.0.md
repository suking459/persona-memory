# persona-memory 1.0.0

面向用户、项目与任务的通用记忆组件：有范围的检索、可纠错的记录、时间版本、候选审阅，以及可选关系状态。核心零运行时依赖，不主动调用模型。

Host-independent agent memory with scoped retrieval, corrections, temporal versions and reviewed learning.

## 可以用来做什么

- 个人/办公助手：保留偏好、长期要求和临时目标。
- 项目/编程助手：保留规范、决定、任务状态与带条件的处理经验。
- 客服系统：保存客户偏好、已确认事项和工单状态，真值由业务系统提供。
- NPC、社区和陪伴机器人：组合关系状态、剧情/任务记录和沟通风格。
- 多工具协作：按明确主体提供记忆和上下文，宿主负责授权与任务执行。

## 包含的能力

- user/project/task 主体和六种类型；结构化 JSON、来源、证据编号、独立寿命与删除。
- 明确范围的词法检索、完整预算、选中/省略解释、真实模型使用确认与有界去重。
- 显式替代、修订冲突、未来生效/历史获知查询和有限版本。
- JSON/内存/可插拔存储，文件锁与内容修订检查，选择性导出、映射预览和整批导入。
- 有期限候选的提出、修订、接受/拒绝；宿主抽取、可选有限接纳策略与任务经验。
- 可选关系分、信任/熟悉维度、可纠正标签、过期衰减与风格统计。
- Node/TypeScript、HTTP、MCP、审阅 CLI、平台消息解析和框架桥。

## 验证与修复

发布前加固基线完成 Windows 六组合、Ubuntu 五组合；完整套件分别 276/279 项（Node 18 为核心 267/270 项）。另有 22 次真实进程在提交前后被强杀的恢复、类型、合成评估、离线安装与 10,000 组 JSON 字节边界检查。Linux 本地基线使用隔离仿真和测试专用等待倍率，生产限制不变。

本版修复快照 getter/toJSON 执行、非法 UTF-8 静默替换、增长文件超量读取、临时文件归属、原型同名 ID、自定义维度、独立候选容量、本地 Host 检查与 MCP 输出背压等问题。最终 1.0 元数据和源码在发布前重新执行测试/安装核对与 [GitHub CI](https://github.com/suking459/persona-memory/actions/workflows/ci.yml)。

## 安装与升级

```sh
npm install "github:suking459/persona-memory#v1.0.0"
```

或从本 Release 下载 persona-memory-1.0.0.tgz：

```sh
npm install ./persona-memory-1.0.0.tgz
```

npm registry 独立管理。新快照 schema 5，支持读取迁移 schema 1–4。升级前停止旧写者并备份；旧实现拒绝新文件，回退使用旧代码和升级前快照。纯预览不计使用，调用方需在模型成功使用后明确确认。详细变化见 [迁移说明](../migration.md)。
