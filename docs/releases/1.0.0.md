# persona-memory 1.0.0

Historical release: scoped user/project/task memory, correction, temporal versions, reviewed learning and optional relationship state. Zero runtime dependencies; no automatic model calls.

Use cases: personal/office preferences and goals; project constraints/decisions/task experience; business-confirmed support records; NPC/community/companion state; explicitly authorized multi-tool memory. Hosts own identity, execution and factual authority.

Includes six typed kinds and bounded JSON; provenance/evidence/lifetimes/deletion; scoped lexical recall/whole-context budgets/reasons/use confirmation; replacement/revision conflicts/future and known-time queries; bounded versions; JSON/memory/custom storage, locks/content revisions, selective transfer/mapping/atomic import; expiring proposal/revision/accept/reject; host extraction/optional bounded acceptance/experience; social scores/dimensions/correctable tags/decay/style; SDK/HTTP/MCP/review CLI/platform parsers/framework bridges.

## Verification

Pre-release baseline: six Windows/five Ubuntu combinations, full 276/279 respectively; Node 18 core 267/270. Twenty-two actual process kills before/after commits, types, synthetic evaluations, offline installation and 10000 JSON byte-bound checks. Linux local baseline used isolated emulation/test-only timing allowances without production relaxation.

Fixes covered getter/toJSON execution, invalid UTF-8 replacement, growing-file reads, temporary-file ownership, prototype-named IDs, dimensions, candidate capacity, local Host and MCP backpressure. Final 1.0 metadata/source underwent tests/install checks and [CI](https://github.com/suking459/persona-memory/actions/workflows/ci.yml).
