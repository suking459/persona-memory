# 1.5 发布候选清单

日期：2026-11-02。当前仍是本地 1.5.0-dev.0；这份清单不授权推送、打标签、改发布历史或发布 npm。

| 项目 | 当前要求 |
|---|---|
| 用户流程 | 使用 [接入与日常管理](agent-operations.md) / [English](agent-operations.en.md)，新包自带 owner.mjs 与 OPERATIONS.md；明确安装、候选、更正、遗忘、停用与恢复 |
| 功能回归 | 以本批最终冻结源码的 Windows / Linux 结果为准；不拿上一轮源码结果冒充新批验收 |
| 安装包 | 同一 tarball 全新离线安装，实际运行生成的 owner 入口；检查安装路径、数据恢复、受保护启用/撤销与私有文件排除 |
| 真实宿主 | [验收矩阵](AGENT-ACCEPTANCE.md) 中指定 Windows Codex CLI / DSH headless 已有各五场景模型实测；本批管理入口是独立 CLI 验证，不新增桌面 UI 结论 |
| 其他厂商 | 九类配置继续实验性标记；若 1.5 明确不承诺其真实支持，无需让用户为发布而安装订阅全部产品。任何新增支持承诺都要有相应宿主验收 |
| 多语言 | 原文保留、locale 和检索机制已有测试；生成操作说明支持中英，其他语言回落英文；不承诺所有语种理解或跨语言准确率 |
| 语义服务 | 保持可选，不默认联网/下载模型；没有真实语义质量分数就不宣传收益比例 |
| 来源和版权 | [来源收尾状态](1.5-SOURCE-STATUS.md) 仍有未决项；不以新增功能掩盖旧分发表达，保留声明，完整包尚不具备“来源全部核清”的结论 |
| 数据和恢复 | 不分发原始聊天、凭据、绑定、私有审计/备份/测试日志；schema 6 升级前备份，回退使用旧版可信备份 |
| 发布批准 | 上述事项形成可核查结果后，由所有者决定版本和范围；此前不推送或发布 |

当前重点是缩小实际承诺和完成来源处置；不为了编号进入 1.6 或承诺所有桌面产品已经适配。桌面接入若要作为正式支持入口，需要另行批准在真实宿主中启用并验收。
