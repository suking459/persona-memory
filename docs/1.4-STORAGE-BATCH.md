## 内容

- 可选内置 SQLite，不新增运行时依赖；Node 18/20 保留 JSON，SQLite 只在明确选择时加载，需 Node 22.13+。
- 同步/异步快照接口，真实事务、CAS、立即锁拒绝、应用身份和严格表结构核对、每操作关闭连接。拒绝外来数据库、意外 schema/日志模式、链接及设备路径；不自动抢锁或重试。
- 完整逻辑备份，SHA-256 完整性、原文和派生引用保留、旧 schema 验证升级、恢复前替换计数及十分钟预览。
- 恢复复核源校验和、目标内容/修订/配置；最后 CAS，写失败不提前替换内存。异步写期间的新本地编辑保留，明确报告已提交但需重载。
- 所有者 CLI 备份、恢复预览/执行；跨路径/机器用明确 identity-from 保留逻辑身份，默认不继承审阅授权。配置生成、owner inspect/review、实际 stdio MCP 可选择 SQLite。

## 审查发现

SQLite 定向测试复现旧同步 flush 把内部日志的 undefined 字段直接传给严格 JSON 存储的问题。现在 export 先做有大小/深度/节点预算的数据复制，只对内部可选空字段采用 JSON 的省略规则，拒绝 getter/toJSON，不调用用户回调；flush 使用该快照。原有全套回归通过后再固定源码做环境矩阵。

Windows 无文件符号链接权限，相关 Windows 用目录 junction 验证拒绝；Linux 另外验证真实文件符号链接。中断测试覆盖子进程事务未提交退出，不声称等价于断电耐久性。
