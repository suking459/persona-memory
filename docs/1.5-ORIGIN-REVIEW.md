## Notices and remaining risk

The [MIT text](https://opensource.org/license/mit) requires applicable notices when copies/substantial portions are redistributed; choosing MIT for this project does not erase third-party obligations. [US Copyright Office software guidance](https://www.copyright.gov/register/tx-programs.html) distinguishes expression from ideas/program logic/algorithms. These references inform the technical assessment, not a universal legal ownership ruling.

Evidence supported preparing a future-version proposal: maintainer-only root copyright line with complete MIT text, truthful historical NOTICE boundaries, and no unverified original-plugin author listed as a present code contributor. At review time this was not applied and was not permission to strip required notices.

Preserve published history/rights, actual redistributed dependency/source licenses, and any required notice if later evidence identifies retained protected third-party expression. Optional frameworks/development packages are not project-authored code. Unknown original-plugin provenance remains a risk; the comparison excludes the whole web/commercial code universe; adaptation/substantiality requires both factual and legal judgment. Prior access to old code prevents a separate-team clean-room claim. Git names and AI-assistance records do not establish legal title or exclusive copyright over every line.
