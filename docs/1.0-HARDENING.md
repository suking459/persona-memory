## Linux 仿真与测试条件

TCG 是 CPU 仿真。第一轮暴露了测试设施的假设：Node 18 的内部文件读取会命中 monkeypatch、异步回调可能尚未开始就到短测试期限、进程启动耗尽外部 watchdog。它们与产品缺陷分别记录，没有删掉失败断言。

修正测试文件读取后的还原顺序，以及迟到回调测试的启动余量。新增开发专用 PM_TEST_TIMEOUT_SCALE（1–20）和 PM_TEST_CONCURRENCY（1–64）。本次 Linux 最终矩阵用 scale=10、concurrency=1；Windows 使用默认 scale=1 和原默认并发。

缩放仅作用于测试驱动的外部 watchdog 和两项回调测试的等待余量。src 与 adapters 不读取这些环境变量；生产模型调用期限、存储限制和输入上限没有放宽。Linux 额外检查真实 FIFO、符号链接、只读目录，故比 Windows 多 3 项；这些权限测试没有跳过。

复现命令（Linux 仿真条件）：

```sh
npm ci --ignore-scripts --no-audit --no-fund
PM_TEST_TIMEOUT_SCALE=10 PM_TEST_CONCURRENCY=1 npm test
npm run typecheck
npm run evaluate
npm run evaluate:retrieval
npm run evaluate:learning
npm pack --dry-run --ignore-scripts --json
```

Node 18 使用 package.json 的 test:core 列表并追加 --test-concurrency=1，避免加载已不面向 Node 18 的可选 SDK。常规机器默认 npm test 不启用仿真倍率。CI 已配置 Windows/Ubuntu 的 Node 20/22/24/26，另保留 Node 18 核心；本次没有推送或触发远程 CI，不借用旧修订的检查。

## 修复与回归覆盖

新增 22 项公共回归，以及 3 项 Linux 文件系统测试。修复前失败日志、修复后日志和冻结清单保留在本地忽略的 .artifacts/platform-audit。

- 文件与传输编码：非法 UTF-8 在磁盘、HTTP、MCP、审阅 CLI 中明确失败，防止静默变成 U+FFFD 后命中另一条合法 ID。坏文件和现有状态保留。
- 有界读盘：stat 后文件增长仍受实际读取 maxBytes+1 上限约束；只接受普通文件，拒绝链接、FIFO、设备，避免打开命名管道导致无限等待。打开后再次检查文件类型。
- 临时文件归属：独占创建成功后才拥有清理权；模拟名称碰撞不会删除其他文件。已经完成提交而锁文件消失时，不把 ENOENT 变成假失败。
- 完整快照：自行实现无 getter/toJSON 执行的 JSON 复制，限制全部编码字节、32 层、2,000,000 节点；未知字段也计入额度。import 和异步 reload 共用该边界，不先序列化不受信数据；失败不替换状态、不遗留 busy。
- 身份字典：toString/valueOf/hasOwnProperty/__defineGetter__ 等合法编号只取自身数据，不读写继承函数。覆盖消息、标签、访客、使用确认、维护、删除、重载与自定义维度缺值恢复。
- 独立候选池：即使正式 maxMemories=0 仍可保存待审候选；接受时再按真实容量拒绝，整次操作不半写。
- 本地 HTTP：所有路由先验证回环 Host 与实际端口；伪造外部 Host 无法取得状态。Origin/管理开关/Bearer 继续各自负责原有边界。回归是直接构造 Host 的确定性测试，不宣称完成真实浏览器的攻击演练。
- MCP stdio：顺序处理请求，stdout 返回 false 后等待 drain，向输入传播背压，避免无限排队。输入最多 1 MiB，拒绝坏编码；EOF 的完整末条 JSON 可以没有换行。

完整套件同时保留既有超时、迟到结果、取消、递归调用、重试、容量饱和、固定种子状态回放、版本冲突、删除/迁移和实际双进程写者竞争检查。没有为通过测试删掉容量或持久化约束。

## 异常退出和适用范围

在写临时文件时与 rename 刚完成后，分别让真实子进程 SIGKILL，随后用新读取校验：提交前保留旧完整 JSON，提交后读取新完整 JSON。遗留锁使后续写者 ERR_STORE_LOCKED，要求宿主明确恢复，不自动抢锁或无限重试。Windows 六个运行时 12/12、Linux 五个运行时 10/10，共 22/22。

这是进程异常退出验证，不能推出断电、磁盘控制器、目录元数据刷盘、网络文件系统或不遵守协议的写者也安全。POSIX 符号链接拒绝与 Host 检查也不能代替宿主的目录权限或完整身份授权。

未验证 macOS/ARM、网络盘、真实模型抽取质量和实时 Discord 长期运行；未读取 QQA 的真实聊天或修改 QQA。核心实现仍为零运行时依赖，保留原有来源和版权。
