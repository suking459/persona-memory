# 0.6 review record

Historical record, 2026-10-29. Reviewed the preceding typed-memory batch before starting 0.7. Local regression success did not certify zero defects or reuse old CI as current-source evidence.

## Reproduced fixes

| Issue | Before | Fix |
| --- | --- | --- |
| Unicode key order | Locale collation treated distinct keys as equal and insertion-order retries conflicted | Deterministic binary string order |
| Reused pruned ID | Surviving history still referenced the ID, so rebinding could produce an unloadable snapshot | Reserve referenced IDs; validate missing-node slot/revision/links/time |
| Forget via pruned ID | Surviving adjacent links were ignored and old content remained | Resolve the logical field from retained references and remove its history/summaries |
| Special collection properties | Getters ran; hidden/symbol entries disappeared | Validate own data descriptors before mutation, without executing getters |

Of 12 new audit tests, 11 failed before fixes. All 12 plus three boundary/disk-failure tests passed afterwards. Fixed regressions were retained because random replay alone did not reproduce every known failure.

## Limits

ID idempotency lasts only while identity/links are retained. New observations need new IDs and bounded retry windows. `removed:0` for an unidentifiable ID does not prove its entire historical field was deleted; list retained inactive versions for a known subject/kind/key, then forget a returned ID, or delete the whole subject.

Environment: Windows / Node 24.16.0. No current-source Linux or other-Node matrix ran in this batch; older 0.4 CI was not substituted. Final 1.0 required its own matrix/install gate. Work stayed in this project; QQA, real chats and external models were untouched.
