# 1.5 接入与操作收尾

日期：2026-11-02。本批保持 1.5.0-dev.0，本地未发布。

## 变更

生成的接入包新增固定绑定的 owner.mjs、中英 OPERATIONS.md 和 manifest 引用。所有者不再反复输入绑定路径，即可检查候选、独立审阅、更正后读取、备份、预览遗忘和恢复。help 不改宿主或创建数据。Codex 的 enable 只面向指定项目；disable 保留后续编辑，目录链接拒绝触及其目的地。DSH 给出已验证 headless 入口的本次 overlay 与明确状态任务，不编造桌面导入步骤。

生成包原来的说明引用不存在的包内 docs 路径，本批改为指向实际 OPERATIONS.md。所有者入口通过安装位置的绝对模块 URL 调用原有 CLI，不使用 shell 拼接、不处理模型凭据、不增加后台循环或运行时依赖。
