## Timing fixture correction

The initial Linux run had 638/639 passes and one failure: the cancellation fixture assumed an extractor callback would start within a 10 ms lease. Under emulation, the correct pre-entry deadline check could refuse the callback first, leaving the fixture's signal variable unset. The test now uses the existing test-only timeout scale with a 100 ms base; production leases are unchanged. A separate deterministic test blocks the event loop past a 10 ms deadline and verifies that extraction never starts and no candidates are written. Raw initial source hashes and failure logs remain separate under the private initial directory.
