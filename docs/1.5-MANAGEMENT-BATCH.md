## 新增

- 只读 doctor：绑定存储可打开、快照结构、范围内候选/过期状态、受限的派生可用性检查、访问权限提示；不自动修复、不查询外部服务。
- 本地召回解释：原文、匹配词、排序原因、范围/预算与记录有效性。它明确区分词法路径与可选语义检索，分数不当作置信度。
- 1–32 项候选接受/拒绝预览；旧值/新值、真实证据引用和质量提示。整批预检，单次 CAS 提交，失败不提前修改当前内存池。
- 删除影响预览：历史、传递派生字段和相关候选计数，样本有界；当前头/修订、来源状态、目标版本/内容和十分钟有效期复核。
- owner CLI 预览文件绑定当前物理配置；MCP 预览属于单连接、16 份上限，返回数据脱离内部计划；默认 capture 没有执行权限。
- 英文操作/恢复指南，中英接入工作流更新；离线安装中覆盖新增管理路径。

## 审查重点

管理操作直接复用 1.4 的全快照恢复/CAS 防护，避免再造另一条持久化算法。异步操作保持连接互斥；失败停用连接，已提交但本地需重载时明确区分，不把已发生的提交说成失败回滚。大批多语言原文预览在写入前按输出预算拒绝，提交回执只返回 ID/计数，防止写成功后因回执过大被当作失败。

新增定向用例包括真实 MCP 子进程、同字段竞争、过期/篡改/变化预览、越范围/越权限、链接/坏存储保护、只读无网络、预览容量/回调边界、锁等待与故障回执。最后静态复核复现 ID 首尾空白导致“找到但解释未选中”，统一规范化并加入回归；另根据 SQLite 官方恢复日志约束，复现并拒绝多硬链接数据库，原始别名内容保持不变。修正后重新冻结源码和运行全部环境检查，旧验证记录独立保存。

Windows 最终 Node 18 核心 495、Node 20 完整 504、新版四组完整各 519 项与类型/原有评估通过；最终 Linux 和安装结果收尾后记录。
