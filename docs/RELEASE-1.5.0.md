# persona-memory 1.5.0

General memory for users, projects and tasks; stable midpoint consolidation selected by the owner.

## Breaking default changes

Built-in emotion/health word lists and relationship tones were removed. Bands are now band-0…band-4. Host judgments replace default text inference; custom rules/stored data remain. Do not assume ^1.0.0 upgrades without migration. Pin versions, back up and read [policy migration](1.5-POLICY-MIGRATION.md). Schema 6 reads 1–5; rollback uses pre-upgrade data.

## Additions

Scoped Agent MCP, default proposals/separate review, per-call refresh and 11 configuration profiles; exact Windows Codex CLI/DSH headless have five real-model cases each, others remain experimental. Dependency fingerprints/invalidation/cascading forget, candidate hints and original-language retrieval; optional semantic fallback/native SQLite/CAS; full integrity-checked backup/restore/identity migration; doctor/lexical explanation/batch and deletion previews; fixed owner.mjs and localized operations guidance.

## Origin and limits

Maintainer-directed, AI-assisted implementation. Located risky expressions/lists were removed and policy/lifecycle rewritten against a prior specification. Comparison of 144 code targets with 999 fixed snapshots and an 88-file matrix confirmed no distinctive retained third-party implementation within that evidence set. This does not establish worldwide originality or ownership of all rights. Truthful history, actual component licenses and earlier license rights remain. See [NOTICE](../NOTICE.md) and [origin review](1.5-ORIGIN-REVIEW.md).

Six Windows runtimes, isolated emulated Ubuntu 543 plus types and same-package offline consumption passed; final CI/assets were separately checked. No universal host/desktop/platform certification, real semantic accuracy or zero-defect guarantee. Core has no runtime dependencies or default model requests.
