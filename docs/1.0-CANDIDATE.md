# 1.0 scope and release gate

Historical frozen 1.0 scope, schema 5, incorporating internal 0.4–0.9 batches. See [release notes](releases/1.0.0.md).

Scope: dependency-free Node core; user/project/task and six typed kinds; optional social state; provenance/evidence/correction/bounded versions/effective and known time; record/store revision conflicts; bounded scoped lexical retrieval/whole-context budgets/explanations/use confirmation; reviewed candidates, constrained host extraction, default-off bounded new-field acceptance and conditional experience; framework/platform bridges, HTTP/MCP/review CLI/examples/synthetic evaluation/migration/deletion. Schemas 1–4 migrate. No complete event sourcing, SQLite, automatic identity merge, autonomous background engine, cloud hosting or full document RAG in 1.0.

Defaults: maxMemories 10000, maxVersionsPerMemory 32, state 48 hours, episode 90 days; candidates 72 hours, 1000 rows and 4 MiB. Sync APIs remain; async stores use open/persist/reload. Preview does not count use or establish truth. Current status means latest head; effective intervals choose current values. Rollback restores pre-upgrade data/code, not a header edit. Deletion includes internal retained versions/candidates/references, not external logs/backups/framework history.

Hardening baseline: Windows six combinations, Node 18 core 267 and modern full 276; Ubuntu five, core 270/full 279 with real FIFO/link/permission checks. Old-source-generated fixtures migrated and old writers preserved rejected new files. Both systems passed clean install/types/CLI/MCP, 22 real interrupted writers, 10000 JSON byte checks and then-known dependency advisory audit. See [hardening](1.0-HARDENING.md) for source digest, TCG test-only scale 10/serial execution and limitations. Production limits were not relaxed.

Final gate required matching package/lock/runtime 1.0.0 metadata; consistent README/use cases/API/migration/change notes and runnable minimal example; final-source tests/types/evaluations/offline install; exclusion of secrets/chats/private snapshots/backups/observations/VM; final candidate CI before merge/tag/release; source/asset versions and checksums tied to the same commit. Actual historical publication is recorded in [GitHub Releases](https://github.com/suking459/persona-memory/releases) and [CI](https://github.com/suking459/persona-memory/actions/workflows/ci.yml); npm publication was separate.

Real-model/platform benefit claims require their own evidence. Unmeasured quality was not marketed as improvement, and independent live apps were not changed to collect demonstration data.
