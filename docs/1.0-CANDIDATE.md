# 1.0 范围与发布验收

1.0 的实现范围已冻结，快照 schema 5。早期 0.4–0.9 开发批次统一进入 1.0，独立发布说明见 [1.0.0](releases/1.0.0.md)。

## 功能范围

- 独立 Node 核心，零运行时依赖；用户/项目/任务主体、六种通用记忆、可选关系状态。
- 来源、证据编号、明确纠错、有限版本、生效/获知时间；记录级修订和存储级内容修订各负责一层冲突。
- 明确范围的有界词法检索、完整上下文预算、选中/省略解释、实际使用确认。
- 候选审阅、宿主受限抽取、默认关闭的有限新字段接纳策略、带条件的宿主任务经验。
- 平台/框架桥、HTTP/MCP、审阅 CLI、例子、合成评估、旧格式迁移与删除。
- schema 5 独立候选集合；支持 1/2/3/4 迁移，旧写者拒绝新格式。

不含完整事件溯源、SQLite、自动身份合并、后台自主代理、任务执行引擎、云托管或完整文档 RAG。

## 默认值和兼容

maxMemories=10000、maxVersionsPerMemory=32；state 默认 48 小时、episode 默认 90 天。候选默认 72 小时、1000 条、4 MiB；数量与字节共同约束。完整边界见 typed-memory.md、retrieval.md、time-storage.md、learning.md。

同步 ingest/putMemory/buildContext 等入口保留；纯异步存储用显式 open/persist/reload。预览不增加使用，使用确认不提高事实真实性。status=current 是最新版本头，当前事实按生效区间读取。回退使用升级前备份，不能只改 schema 号。

完整删除覆盖候选、保留版本与内部派生引用；外部日志、备份和框架历史仍由宿主管理。

## 已完成的底层基线验收

- 功能及公开入口、类型、合成分类/检索/连续学习评估。
- Windows 六组合：Node 18 核心 267 项，20/22/24/26 完整 276 项，额外覆盖旧 Node 24 补丁。
- Ubuntu 五组合：Node 18 核心 270 项，20/22/24/26 完整 279 项；FIFO/链接/权限检查未跳过。
- 真实旧实现生成的合成快照迁移，旧写者拒绝新格式且保留原文件。
- 两端干净离线安装、消费方类型、CLI/MCP 和关键入口。
- 22 次真实进程中断、权限边界、10,000 组 JSON 字节检查和 npm 依赖已知通告审计。

该基线对应发布前实现，条件和逐文件摘要见 [加固记录](1.0-HARDENING.md)。Linux 使用隔离 TCG 虚拟机与测试专用 scale=10/concurrency=1；生产期限不变。Node 18/20 仅作 EOL 兼容检查，部署选择维护中的 LTS。

## 最终发布关卡

在正式标签与 Release 前完成：

1. package.json、锁文件与运行时 VERSION 一致为 1.0.0，运行时代码和依赖变化明确。
2. 首页、用途、API、迁移及变更说明互相一致；最小示例实际运行。
3. 最终候选的测试、公开类型、合成评估和离线消费检查通过。
4. 发布包/源码中无私人资料、密钥、原始聊天、备份、观察结果和测试虚拟机。
5. GitHub 对最终候选执行支持矩阵；确认对应提交后再合并、标签和发布。
6. Release 资产与该提交的版本、源码和校验值对应。

实际发布状态以 [GitHub Release](https://github.com/suking459/persona-memory/releases) 和对应提交的 [Actions](https://github.com/suking459/persona-memory/actions/workflows/ci.yml) 为准。npm registry 独立管理，不把旧 registry 包当作 1.0 的安装入口。

真实模型/平台声明属于条件门槛。没有声称的效果不包装成收益，也不为演示修改独立线上应用或读取原始聊天。
