# 1.3 可选语义召回与上下文

状态：本地 1.3.0-dev.0，未发布。上一批 1.2 Windows 410 / Linux 413 项、类型和离线安装通过后，保存本地检查点 7521d57，再开始本批。

## 新增

- 固定主体/筛选范围的语义检索适配器：词法＋最近有效候选池、ID 去重、单次有上限的嵌入调用、相似度排序及完整上下文预算。
- Ollama /api/embed 与 float OpenAI-compatible HTTP 接口。地址、模型及环境变量名由所有者配置；默认仍为词法。CLI 和接入包可直接准备配置，不要求使用者另写一个适配器。
- 缓存绑定来源 epoch，更正/遗忘/导入/重载后不可复用旧向量。异步参数先快照，向量脱离回调返回对象，迟到结果不能提交缓存或返回过时记忆。
- HTTP 全程期限/取消、输入与响应上限、重定向拒绝、严格 UTF-8、响应索引与模型变化检查、安全错误回执。没有无限重试、队列或自动拉取模型。
- Agent 异步检索后再检查落盘快照；所有者在查询期间更正内容时，旧结果丢弃并返回新范围内的词法结果；坏快照停用连接，不发缓存答复。
- 明确选择服务的 13 条合成评估入口；人工向量模式与真实配置服务模式分开标注。它们不代替母语质量、生产准确率或真实宿主模型任务。
