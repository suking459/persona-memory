# 1.1 first Agent integration batch

Historical record, 2026-11-01; local 1.1.0-dev.0, unpublished. v1.0.0 tag/assets unchanged.

1.0 lacked a complete Agent proposal/review workflow and model-supplied subject arguments were not an access boundary. The separate adapters/agent service fixes subjects/store at startup; separates read/capture/review and approved/candidate data; binds corrections to heads; rejects stale reviews; scopes forgetting/revision checks; accepts only connection-created context confirmations; and stops a connection after persistence/conflict failures rather than issuing false success.

persona-memory-connect generates 11 host profiles/workflows, including local WorkBuddy metadata and DSH bundles. Explicit apply/undo preserves sibling settings and checks hashes; preparation does not change host settings. Generated artifacts depend on their installed paths and are not portable marketplace packages.
