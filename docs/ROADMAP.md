## 条件研究项

RAG 需要真实召回需求和效果数据；完整事件溯源需要明确的重算、回放、恢复需求。二者不因凑版本号而成为强制重构，也不发布空壳能力。当前先稳定可纠错的状态库、有限变化记录和可靠快照。

LlamaIndex TS core 已被 npm 标记 deprecated，仅保留可选历史兼容桥接，不成为核心依赖。核心保持零运行时依赖。

## 历史验证与发布约束

0.4 基线的 67 项本地测试和合入前 7 项 CI 已通过（Node 18 核心，以及 Windows/Linux 的 Node 20、22、24）。[既有检查记录](https://github.com/suking459/persona-memory/actions/runs/40737573004) 仅证明对应旧修订。

此前已将 0.4 源码更新到 GitHub main，早于约定的统一发布节奏；没有创建对应 Release/标签或 npm 发包。保留这份源码作为基线，不擅自回滚远端。后续本地批次完成不触发推送、标签、Release 或 npm 发布。

## 项目隔离

QQA 是独立线上应用，不改代码、配置、数据、状态或运行方式。只在本项目实现和生成产物，测试使用合成或匿名数据。私人快照、原文、身份、凭据、备份和本地协作记录都不进入发布包。

协作目标和习惯记录在 AGENTS.md 与本地 WORKING-AGREEMENT.md。
