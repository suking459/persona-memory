## 最小后续方案

1. 以 API 行为需求写独立规格，分别处理关系提示文本、标签建议、词表与标签规范化，不看着旧代码逐句换词。
2. 默认内容减少或移除会改变旧关系调用者的行为；先提供实际拟改内容、兼容和迁移说明，再实施有边界的替换。自定义规则与已有正式记忆数据不自动删除。
3. 使用合成场景检查旧快照、候选/审阅、更正/遗忘及循环/容量边界，再对实际分发文件复核残留表达。
