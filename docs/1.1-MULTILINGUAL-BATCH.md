# 1.1 多语言基础修复与复核

日期：2026-11-01。本地分支 work/1.1-development，版本 1.1.0-dev.0。未推送、未发布，未更改 v1.0.0 历史。继承 [首批 Agent 检查](1.1-AGENT-BATCH.md)，不表示整个 1.1 已完成。

## 实际发现与修复

原有 Unicode 保存不等于多语言检索完备。改动前人工构造并保存了以下失败：

| 情况 | 原行为 | 本批结果 |
|---|---|---|
| 泰语 ฉันชอบกาแฟดำ 查询 กาแฟ | 漏搜 | 按运行时词典分词命中 |
| 孟加拉语 কফি 与 কফ | 查询前者同时返回两者 | 保留元音符号，只返回前者 |
| 印地语 कॉफ़ी | 拆掉附加符号，误召回无关内容 | 保留附加符号，不再返回该无关样例 |
| 显式土耳其语 locale | 字段不支持 | 支持土耳其语大小写和按语言处理停用词 |

新 src/locale.js 提供有上限的 BCP 47 校验、16 项 Segmenter 缓存和中英标题；src/retrieval.js 在匹配时规范化，不重写存储原文。新 Agent binding/单次调用/CLI 均可指定 locale，旧 binding 缺该字段默认英文。Agent 显式 null 与非法标签拒绝，不悄悄忽略。语言变化不能增加主体或权限。

复核时还发现通用模型桥重新组装选项时漏传 locale；adapters/memory/index.js 已修复，并用土耳其语实际召回及英文标题回归。原 MCP 有类型记录工具同步声明 locale，HTTP 复用核心查询校验。

接入包新增中英 WORKFLOW/说明；提供 [English onboarding](agent-integration.en.md)、[中文接入](agent-integration.md) 和 [多语言边界](multilingual.md)。不引入运行时依赖，不使用自动翻译或新的付费模型调用。
